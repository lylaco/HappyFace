# HappyFace

A Java application developed in Eclipse.

## Description
This project is a Java-based application. It is done and managed using Git version control.

## Features
* Turning a Happy Face to Sad.
* Integrated Git version control configuration.

## Prerequisites
To run this project, you need:
* **Java Development Kit (JDK):** Version 8 or higher.
* **Eclipse IDE:** (Or any other preferred Java IDE).

## Getting Started

### Installation
1. Clone this repository to your local machine:
   ```bash
   git clone https://github.com
   ```
2. Open Eclipse IDE.
3. Go to `File` > `Import...`.
4. Choose `General` > `Existing Projects into Workspace` and select the cloned folder.

### Running the Application
1. Locate the main Java file containing the `public static void main(String[] args)` method.
2. Right-click the file and select `Run As` > `Java Application`.
